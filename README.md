#### 🩺 [HealthMate – Smart Healthcare Appointment System](https://github.com/AyushGupta-7/HealthMate)
A full-stack web application for managing health records and booking doctor appointments.
- Built a responsive React frontend with modular component design
- Designed RESTful APIs using Node.js & Express for auth, scheduling, and data handling
- Integrated MongoDB for CRUD operations on users, appointments, and health records
- JWT-based authentication with signup/login, dashboard, and appointment management
- Deployed via **Vercel** (frontend) and **Render** (backend)

`React` `Node.js` `Express` `MongoDB` `JWT`

- Handled real-time input variations through careful debugging and analysis

`Python` `OpenCV` `MediaPipe` `Machine Learning`
